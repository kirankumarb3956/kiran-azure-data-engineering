# Data Skew, AQE & Salting — Azure Databricks

Hands-on portfolio project demonstrating how to identify and mitigate Data Skew in Spark/Azure Databricks.

Scenario: one retail `store_id` contains far more records than other keys, creating a hot partition/task.

Topics: skew detection, Spark UI, AQE skew handling, salting, join optimization, performance measurement.

Performance numbers should be replaced with actual Spark UI measurements when you run the project.
